# W01 — Identity Gate authority transitions

IG-01 and IG-02 are repaired in this candidate. Recognition processes expiry
before reading assurance. Activity processes expiry again at its own timestamp
before it updates idle time or extends a verification window. Exact deadlines
are expired. Existing epoch invalidation rejects receipts issued before that
expiry, including when ordinary verification survives a fresh-only expiry.

Recognition, scope evaluation (including capability checks) and verification
requests retain their existing activity semantics. They may extend only live
windows, and only when sliding policy permits it, within provider and hard
limits. Identity claims clear prior verification. Session reads, model packets
and prompt classification process expiry but do not renew windows.

Prompt classification rebuilds instruction permission, trust, data permission
and operator verification from the source class and live session. It clears
GrantedScopes because classification does not authorize individual scopes;
callers use CheckPromptAuthority for that. Source classes are still supplied by
the trusted host integration; this change does not authenticate source labels
received from arbitrary external input.

The two original public probes are now ordinary regression tests. Internal
tables exercise just-before, exact and just-after verified/fresh/idle deadlines
across recognition, scope checks, session reads, classification, model packets
and the shared activity helper. Provenance cases use independently initialized
sessions, all declared source classes, empty/unknown classes and hostile preset
fields. Pending receipts are tested across verified and fresh expiry. Existing
receipt, replay, epoch, provider-limit and hard-cap tests remain intact.

The other 20 known findings remain under the auditregression tag. W02 is not
started. Local verification and a separate self-review are recorded in the
control repository's evidence/aegis-core-w01-20260911 receipt. The plan's
independent reviewer requirement remains an acceptance gate; a self-review
does not satisfy it. Hosted CI and Linux race validation remain separate gates.
